# ExampleCustomRecipes
This mod can be used an example for modders to add custom recipes to the game using a mod.  
Custom recipe mods need to be on both the Client and the Server to work properly.  
Custom recipe mods require that you have https://github.com/CG-Nik/CustomRecipesAPI downloaded for them to work properly.  

If you want an example for how to handle how players should download a mod with AssetBundles, you can look at https://github.com/CG-Nik/MetalHandleMoulds/tree/master.  
In general, MetalHandleMoulds can be used a secondary reference for how to add custom recipes.  

This is an unofficial, fan-made mod for A Township Tale. This mod is not affiliated with or endorsed by the owners or developers of A Township Tale.
